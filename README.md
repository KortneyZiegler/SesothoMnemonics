# SesothoMnemonics
Sesotho Language Learning App with visual mnemonics.

## How to use this project
This repository contains the core SwiftUI files for the Sesotho Mnemonic app. 

### To run the app:
1. Open **Xcode** and select **"Create a new Xcode project"**.
2. Choose **iOS > App** and name it `SesothoMnemonics`. Make sure the interface is set to **SwiftUI**.
3. Delete the default `ContentView.swift` file from your new Xcode project.
4. Drag and drop the `ContentView.swift` and `Flashcard.swift` files from this repository directly into your Xcode project's sidebar.
5. Select the iPhone Simulator at the top and click **Run** (Cmd + R) to see the app in action!
